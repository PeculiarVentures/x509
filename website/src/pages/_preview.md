# @peculiar/x509 — X.509 certificates for JavaScript

Create, parse, and verify X.509 certificates, certificate requests, and CRLs in browsers and Node.js. @peculiar/x509 is written in TypeScript, signs and verifies with WebCrypto, and is built on [@peculiar/asn1-schema](https://github.com/PeculiarVentures/asn1-schema).
