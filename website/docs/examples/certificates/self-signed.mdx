# Create a self-signed certificate

Generate a key pair with WebCrypto and create a self-signed CA certificate. The same `signingAlgorithm` works for RSA (`RSASSA-PKCS1-v1_5`, `RSA-PSS`), ECDSA and Ed25519 keys; set the hash in it, as here.
