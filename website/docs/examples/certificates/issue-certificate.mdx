# Issue and verify a certificate

A CA signs a certificate for a server's public key. To check that a certificate was issued by a CA, pass the issuer certificate as `publicKey` to `verify()`: x509 then imports the issuer key with the hash of the certificate's signature algorithm. A `CryptoKey` is used as is, so it must already match that algorithm, for example `issuer.publicKey.export({ name: "RSASSA-PKCS1-v1_5", hash: "SHA-384" }, ["verify"])` for a certificate signed with `sha384WithRSAEncryption`.
