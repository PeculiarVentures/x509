# Read a certificate

Parse a PEM certificate and read its subject, issuer, serial number, validity period, public key and extensions. `getExtension()` takes an extension class and returns a typed object, or `null` when the certificate doesn't have that extension. `toString("text")` prints the whole certificate in a readable form.
